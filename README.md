# Semi-structured Interview App

Mobile-first web tool for conducting and logging semi-structured field interviews. Built for a doctoral AI internship project at Universidad del Cauca, Colombia.

## What it does

- Step-by-step interview guide with navigation between questions
- Progress tracking per question
- Mobile-optimized layout (max-width 540px, fixed header)
- Universidad del Cauca branding

## Stack

HTML5 · CSS3 · vanilla JavaScript · mobile-first layout
